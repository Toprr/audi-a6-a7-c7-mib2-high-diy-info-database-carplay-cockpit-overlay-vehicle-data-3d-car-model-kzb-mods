# Speed overlay for the mib-cluster-map stream player (work in progress)

Draws a small "52 km/h" box over the CarPlay / Android Auto map in the cockpit. Background, car results and
status: [docs/11](../../docs/11-vehicle-data-logger.md). Written for mib-cluster-map **v1.2.6** on
`MHI2_ER_AU57x_K3663_1`. **Not confirmed in the car yet** (the first test failed because the speed file was
missing, see docs/11).

This is a change to [MacsInSpace/mib-cluster-map](https://github.com/MacsInSpace/mib-cluster-map)'s player
(GPL-3.0). All map work is theirs; this folder only holds our addition.

| File | What |
|---|---|
| `mcm-v1.2.6-opengl_gpu.patch` | the 3 lines added to `player/opengl_gpu.cc` of mib-cluster-map v1.2.6 |
| `player/speed_overlay.h` | the overlay: reads `/tmp/vehlog_speed`, draws with its own small GLES2 shader, never touches the map |
| `player/speed_font.h` | digits and "km/h" as 8-bit alpha bitmaps, generated by `tools/make_font.py` from DejaVu Sans (`player/DejaVu-LICENSE.txt`) |
| `test/raster_test.cc`, `test/position_test.cc` | PC tests with GL stubbed out: the real rasterizer and the position config |

The speed comes from [VehLog](../vehlog/) (read-only Java HMI logger, `/tmp/vehlog_speed`). Without it the
player draws nothing extra. Install and rollback scripts: `tools/vehlog/sd/vehlog/speedoverlay.sh` (only
replaces the player when it is the original v1.2.6 one, sha1 checked, and keeps the original).

## Position

`/mnt/persist/speedoverlay.conf`, read when the player starts:

```
pos=bl        # bl, br, tl, tr
left=200      # pixels from the left edge (bl, tl); the rev counter covers about the left 180 of 800
right=12      # pixels from the right edge (br, tr)
top=12        # pixels from the top (tl, tr)
bottom=12     # pixels from the bottom (bl, br)
```

The player window is 800×298 on the A6/A7 C7.5.

## Build

1. QNX toolchain image from [luka-dev/qnx65-armv7-toolchain](https://github.com/luka-dev/qnx65-armv7-toolchain)
   (tag `8.5`), as mib-cluster-map's `build_local.sh` expects. On Windows: clone with
   `git -c core.autocrlf=false`, then `git -c core.autocrlf=false archive HEAD | docker build ... -` so the
   symlinks and line endings survive.
2. mib-cluster-map at tag `v1.2.6`, apply the patch, copy the two headers to `player/`.
3. `./build_local.sh player`. On Windows run it in a Docker volume, not in a Windows folder (the 32-bit QNX
   `ar` fails on Windows mounts with "Value too large for defined data type").
4. Check: build the unchanged v1.2.6 first; it should be byte-identical to the released player
   (sha1 `0e38137fe58434d6722a09c5e5c67c10e91c0f92`). Run `tools/neon_audit.py` with
   `tools/neon_audit.allow` on the patched build.
